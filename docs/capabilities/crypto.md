# crypto-protocol (P2)

**Issues:** [#104](https://github.com/egao1980/cl-stack/issues/104)  
**Status:** brief **locked** — CLOS protocol + **separate backend repos**; **recipes first, hazmat second**

One app DX for digests, MACs, and authenticated encryption. Libs depend on the protocol; apps pick a crypto backend (default **Ironclad**). Mirrors **PyCA cryptography** (recipes + hazmat), **Java JCA** (MessageDigest / Mac / Cipher), and **OpenSSL 3 EVP** (high-level AEAD) — not Boost (no first-party Boost.Crypto).

**Repos:** [`egao1980/crypto-protocol`](https://github.com/egao1980/crypto-protocol) · backend [`egao1980/crypto-backend-ironclad`](https://github.com/egao1980/crypto-backend-ironclad) (own project — same pattern as `sql-query-*` / `event-backend-*`).

**Related:** [`secrets-protocol`](secrets.md) owns CSPRNG, tokens, constant-time compare, UUID, password hashing.

Conventions: [API.md](../API.md). Gap: [STDLIB-GAP.md](../STDLIB-GAP.md).

## Prior art (what we steal)

| Ecosystem | Surface | Steal |
|-----------|---------|-------|
| **Python** | `cryptography` recipes (`Fernet`) + hazmat AEAD (`AESGCM`) | Safe defaults for app encryption; explicit AEAD when you need AAD/streaming |
| **Python** | `hashlib` / `hmac` | One-shot + incremental update objects |
| **Java** | JCA `MessageDigest` / `Mac` / `Cipher` | Separate primitives; **never** default to bare `AES` (= ECB) |
| **OpenSSL 3** | EVP digest / MAC / AEAD | High-level EVP over low-level `AES_*` |
| **CL** | **Ironclad** | Default backend (pure Lisp; Windows-friendly) |

**Non-steal:** Java string transformation soup (`"AES/GCM/NoPadding"`); exposing CBC/ECB as the cookbook path.

## Locked decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| **Shape** | CLOS protocol + backends | Same as log/cli/sql |
| **Tiers** | **Recipes** (safe) + **hazmat** (explicit) | PyCA lesson — most apps should never pick mode/IV |
| **Default recipe** | `seal` / `unseal` = **AES-256-GCM** sealed blob | AEAD; nonce generated by secrets backend |
| **Default digest** | `:sha256` | Modern floor; SHA-1 not in recipe DX |
| **Default MAC** | HMAC-SHA256 | JCA/Python default strength |
| **Hazmat AEAD** | `:aes-gcm` required for wave-1; `:eax` optional | Ironclad supports GCM/EAX/ETM |
| **Bare CBC/ECB/CTR** | **Not** public recipe API | Hazmat escape hatch only if backend exposes it — cookbook warns |
| **Keys / nonces** | `(simple-array (unsigned-byte 8) (*))` | No strings-as-keys |
| **RNG** | Via **secrets-protocol** | One CSPRNG story |
| **Password hashing** | **secrets-protocol** | Not a Cipher |
| **Signatures / PKI** | Follow-on | Ed25519/RSA-PSS later |
| **Default backend (A)** | **Ironclad** via `crypto-backend-ironclad` (also implements secrets-protocol) | Already imported; pure Lisp |
| **Watchlist (B)** | OpenSSL via cl+ssl / custom EVP | When hardware AES or FIPS matters |
| **Windows** | Required | Ironclad = no native overlay |

### Sealed blob (recipe wire format)

Octets, not base64 (encode at the boundary with serdes/`cl-base64`):

| Offset | Size | Field |
|--------|------|-------|
| 0 | 7 | magic `CLSEAL1` |
| 7 | 12 | nonce |
| 19 | N | ciphertext |
| 19+N | 16 | GCM tag |

Key length for `seal` = **32 octets** (AES-256). Wrong key size → `crypto-key-error`.

## Protocol surface

Package nick: `stack-crypto`.

```lisp
(defclass crypto-backend () ())
(defvar *crypto-backend* nil)

;;; --- Recipes (prefer these) ---
(defun digest (data &key (algorithm :sha256) (backend *crypto-backend*)) → octets)
(defun hmac (key data &key (algorithm :sha256) (backend *crypto-backend*)) → octets)
(defun seal (plaintext &key key aad (backend *crypto-backend*)) → sealed-octets)
(defun unseal (sealed &key key aad (backend *crypto-backend*)) → plaintext-octets)
(defun generate-key (&key (nbytes 32)) → octets)  ; delegates to secrets

;;; --- Hazmat (explicit algorithms) ---
(defgeneric backend-digest (backend algorithm data &key start end))
(defgeneric backend-hmac (backend algorithm key data &key start end))
(defgeneric backend-aead-encrypt (backend algorithm key plaintext
                                 &key nonce aad))  ; → (values ciphertext nonce tag)
(defgeneric backend-aead-decrypt (backend algorithm key ciphertext
                                 &key nonce tag aad))  ; → plaintext or signal

;;; Incremental digests / MACs
(defgeneric make-hasher (backend algorithm))
(defgeneric update! (ctx data &key start end))
(defgeneric finalize (ctx) → octets)
(defgeneric make-mac-ctx (backend algorithm key))

;;; Conditions
(define-condition crypto-error (error) …)
(define-condition crypto-authentication-error (crypto-error) …)  ; bad tag
(define-condition crypto-key-error (crypto-error) …)
(define-condition crypto-unsupported (crypto-error) …)
```

**Recipe rule:** `seal` always generates a fresh nonce via secrets; callers never supply one. `unseal` fails closed on bad magic / bad tag (`crypto-authentication-error`).

## Non-goals (wave-1)

- Full PKI / X.509 / TLS (→ cl-stack-ssl)
- Homegrown CBC+HMAC “Fernet clone” when GCM works
- Algorithm agility negotiation protocols
- HSM / PKCS#11
