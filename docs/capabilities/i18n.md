## Prior art

| Ecosystem | Analogue |
|-----------|----------|
| **ICU** | `Locale`, `message2::MessageFormatter`, PluralRules, ResourceBundle |
| **Python** | `babel`, `gettext`, fluent |
| **Java** | `Locale`, ICU MF2 / `ResourceBundle` |

---

## Locked decisions

| Decision | Choice |
|----------|--------|
| Templating | **MF2** (`make-message-formatter` / `format-message`) — ICU MessageFormatter |
| Locale | BCP 47 tags + `locale` class; `*locale*` dynamic |
| Catalogs | Backend-agnostic `translate` / `ntranslate` (not hard-wired to gettext) |
| Formatting numbers/dates inside messages | Handled by backend (often via l10n); protocol does not embed numfmt |
| Collation / standalone numfmt | **Out** → `l10n-protocol` |
| Unicode properties | **Out** → `unicode-protocol` |

---

## DX

```lisp
(stack-i18n:format-message "Hello {$name}!" '(("name" . "Ada")) :locale "en")
(stack-i18n:with-catalog cat
  (stack-i18n:ntranslate "items" 3))
```
